Подробное описание

Обработка динамического массива целых чисел.

Программа:

  • запрашивает размер массива N и его элементы;
  • выводит исходный массив;
  • находит индекс первого отрицательного элемента;
  • если такой элемент есть, обрезает массив до элементов, стоящих перед ним;
  • освобождает память и обнуляет указатель.

◆ process()

void process ( int *& arr,
int & size )

Обрабатывает динамический массив: находит первый отрицательный элемент и обрезает массив до позиции перед ним.

Аргументы
[in,out]arrСсылка на указатель на динамический массив. При обрезании старое содержимое освобождается, а указатель перенаправляется на новый массив меньшего размера. Если отрицательных элементов нет, указатель не меняется.
[in,out]sizeСсылка на размер массива. После обрезания содержит индекс первого отрицательного элемента (новый размер).

Алгоритм работы:

  1. Линейный поиск первого элемента со значением < 0.
  2. Если элемент не найден — массив остаётся без изменений.
  3. Если найден — создаётся новый массив длиной negIndex, куда копируются все элементы исходного массива до найденного индекса.
  4. Старый массив освобождается через delete[], указатель и размер обновляются.
Заметки
Функция изменяет владельца памяти: после вызова arr указывает на новый массив, который должен быть освобождён вызывающей стороной.
Предупреждения
Если arr == nullptr, поведение не определено.
Не проверяет отрицательное значение size. При size < 0 возможен выход за границы массива.

Индекс первого отрицательного элемента; -1, если не найден.

Новый массив, содержащий только элементы до первого отрицательного.

< Перенаправляем указатель на новый массив.
