Подробное описание

Работа с безопасным динамическим массивом целых чисел.

Программа:

  • создаёт динамический массив через структуру SafeArray;
  • предоставляет безопасный доступ к элементам с проверкой границ;
  • изменяет размер массива с сохранением данных;
  • освобождает выделенную память.

◆ createArray()

SafeArray createArray ( int size)

Создаёт новый динамический массив.

Выделяет память под заданное количество элементов и возвращает структуру SafeArray по значению.

Аргументы
sizeРазмер создаваемого массива.
Возвращает
Созданный объект SafeArray.

◆ getElement()

int & getElement ( SafeArray & arr,
int index )

Возвращает элемент массива по индексу с проверкой границ.

При корректном индексе возвращает ссылку на настоящий элемент массива. При ошибочном индексе возвращает ссылку на временную безопасную переменную.

Аргументы
arrМассив, из которого берётся элемент.
indexИндекс элемента.
Возвращает
Ссылка на элемент массива.

◆ main()

int main ( )

Точка входа в программу.

Последовательно выполняет:

  1. Создание динамического массива SafeArray.
  2. Заполнение массива начальными значениями.
  3. Проверку изменения элемента через getElement().
  4. Проверку обработки неверного индекса.
  5. Изменение размера массива функцией reSizeArray().
  6. Освобождение памяти.
Возвращает
Код завершения программы.
Заметки
После освобождения памяти указатель data обнуляется.

◆ printSafe()

Выводит содержимое массива на экран.

Массив передаётся по константной ссылке, поэтому функция не может изменить его содержимое.

Аргументы

◆ reSizeArray()

int M )

Изменяет размер динамического массива.

При уменьшении размера удалённые элементы выводятся на экран. При увеличении новые элементы инициализируются нулями.

Аргументы
