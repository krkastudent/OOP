Подробное описание

Работа с двумерным динамическим массивом (матрицей).

Программа:

  • выделяет память под двумерный массив;
  • заполняет матрицу данными пользователя;
  • выводит матрицу с разными параметрами отображения;
  • освобождает выделенную память.
