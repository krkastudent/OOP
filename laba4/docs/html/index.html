Устройства умного дома - вариант 5

Иерархия

SmartDevice -> PoweredDevice -> LightBulb, Thermostat, SmartOutlet. SmartOutlet дополнительно реализует интерфейс ISensor.

Данные и тесты

Из devices.txt загружаются 4 лампы, 3 термостата и 3 розетки. SmartDevice, PoweredDevice и ISensor абстрактные и отдельно не создаются. Один tests.cpp используется для клиентов статической и динамической библиотек.

Учёт энергии и копирование

При выключении учитывается расход: Вт * секунды / 3600000 = кВт·ч. Копии сохраняют состояние и параметры, но начинают собственный отсчёт времени. string обеспечивает независимое владение строками.
